# CoffeeLab

Магазин и кофейня с онлайн-заказом, личным кабинетом и админ-панелью со статистикой.

## Стек

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- Tailwind CSS + [shadcn/ui](https://ui.shadcn.com)
- PostgreSQL + [Prisma](https://www.prisma.io)
- Redis
- Собственная система авторизации (JWT + refresh-токены)

## Разработка

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).
